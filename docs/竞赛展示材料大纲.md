## 四、预判 QA

| 问题 | 应答要点 |
|------|---------|
| LLM 在这里到底是做什么的？ | 伪代码解读、崩溃原因解释、exploit 迭代修正。不替代传统工具，而是补强研判环节 |
| 和 PwnGPT 有什么区别？ | PwnGPT 追求 LLM 端到端生成 exploit；我们更务实，LLM 作为辅助组件与传统工具协同 |
| 为什么不全自动？ | 真实二进制情况复杂，全自动成功率低且不可控。辅助式方案更适用于教学和研究场景 |
| 实际效果如何？ | 给出四维评估数据和样本测试统计 |
| 创新点在哪里？ | checksec→CVSS 映射、MAB自适应调度、LLM+传统融合框架、验证闭环 |

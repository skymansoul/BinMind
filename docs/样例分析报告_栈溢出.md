# 样例分析报告：栈溢出漏洞 (ret2libc)

## 基本信息

| 字段 | 值 |
|------|-----|
| 样本名称 | `vuln_stack_bof` |
| 样本来源 | 教学样本（自编） |
| 漏洞类型 | stack-buffer-overflow |
| 架构 | x86-64 |
| 保护措施 | NX✓ PIE✗ Canary✗ Partial RELRO |

## 样本源码

```c
#include <stdio.h>
#include <unistd.h>

void vuln() {
    char buf[64];
    puts("Enter input:");
    gets(buf);  // 危险: 无边界检查
    puts(buf);
}

int main() {
    vuln();
    return 0;
}
```

编译: `gcc -fno-stack-protector -no-pie -o vuln_stack_bof vuln.c`

## 分析流程

### 1. 程序画像

## 经验总结

1. 无 Canary + 无 PIE 的场景下，ret2libc 可靠且有效
2. LLM 在伪代码解读阶段提供了有价值的语义注释
3. 反馈环的第1次迭代（调整了 puts_got 地址）是成功的关键
4. 若样本有 Canary 保护，需要先识别 canary 泄露路径

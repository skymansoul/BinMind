## 当前模块描述
漏洞检测模块：漏洞数据库、漏洞管理、LLM 漏洞检测器、利用生成流水线、模糊测试编排、YARA 管理、供应链检测、漏洞去重。

## 设计的深度创新点: CPG 引导 LLM 漏洞检测 + 反事实增强鲁棒性 (CPG-LLM-Vuln)

### 创新动机与理论依据
现有 LLM 漏洞检测器以源码文本为输入，缺失结构信息。借鉴 LLMxCPG：构建代码属性图（CPG）并将关键路径序列化为 LLM 上下文，提升跨函数数据流理解；借鉴 VISION 的反事实增强，对训练样本做最小扰动生成对抗样本，提升检测器对攻击性扰动的鲁棒性；借鉴 CodeSAGE 的多特征融合注意力。差异点：现有输入为纯文本，新增方案引入 CPG 结构与反事实正则。

### 支撑论文
  [1] LLMxCPG: Context-Aware Vulnerability Detection Through Code Property Graph-Guided Large Language Models — arXiv:2507.16585 (2025).
  [2] VISION: Robust and Interpretable Code Vulnerability Detection Leveraging Counterfactual Augmentation — arXiv:2508.18933 (2025).
  [3] CodeSAGE: A multi-feature fusion vulnerability detection approach using code attribute graphs and attention mechanisms — Journal of Information Security and Applications (2025).
  [4] NatGVD: Natural Adversarial Example Attack towards Graph-based Vulnerability Detection — arXiv:2510.04987 (2025).

        return sum(len(vulns) for vulns in self.vulnerabilities.values())

        nCount = 0
        for vulns in self.vulnerabilities.values():
            for vuln in vulns:
                if vuln.severity == 'Critical':
                    nCount += 1
        return nCount

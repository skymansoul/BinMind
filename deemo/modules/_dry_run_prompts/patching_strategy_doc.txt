## 当前模块描述
自动补丁模块：补丁差异定位、补丁建议生成、自动补丁规范、自动打补丁、自动根因分析、重编译检查、CVE 知识库、补丁报告生成。

## 设计的深度创新点: 神经符号 + 静态分析/测试反馈的智能体修复 (AgentRepair)

### 创新动机与理论依据
现有补丁建议依赖规则模板，缺乏执行反馈闭环。借鉴 Agentic Program Repair的神经符号框架：将修复建模为多轮 agent 循环，每轮由静态分析提供候选位置与约束、由测试执行反馈验证修复有效性，失败则回溯重试；借鉴 SynthFix 的自适应神经符号修复，对漏洞类型做分类并选择符号约束或 LLM 生成路径。差异点：现有方案单轮模板生成，新增方案引入多轮验证-回溯闭环。

    SUCCESS = "success"
    FAILED = "failed"
    TIMEOUT = "timeout"
    UNKNOWN = "unknown"

    @property
    def value(self):
        return self._value_

    def __str__(self):
        return self._value_

    def __eq__(self, other):
        if isinstance(other, CompilationStatus):
            return self._value_ == other._value_
        if isinstance(other, str):
            return self._value_ == other
        return NotImplemented

    def __hash__(self):
        return hash(self._value_)

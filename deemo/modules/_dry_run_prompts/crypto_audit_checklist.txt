## 当前模块描述
密码学检测模块。包含加密算法检测（魔数/结构/API 字符串匹配）、密码学误用检测（ECB 模式、静态 IV、弱密钥、硬编码盐值、可预测 RNG）、污点传播、固件加密分析、区块链密码学、CBOM 生成、FPE 检测、后量子算法检测、加密流量解密等。

## 设计的深度创新点: 依赖引导的 LLM 增强密码学误用检测 (DepLLM-Crypto)

### 创新动机与理论依据
现有模式匹配存在高假阳性。借鉴 CRYPTBARA 的依赖上下文方法：(1) 数据流敏感的污点传播路径构建（密钥生成点 → 加密调用点）；(2) LLM 语义验证层——对模式命中的候选误用提取上下游依赖上下文，提交 LLM 二次确认，消除静态规则假阳性；(3) 跨文件常量折叠传播——跟踪硬编码密钥/IV 是否跨编译单元传递；(4) 借鉴 arXiv:2510.18601 的 secrets 检测经验做密钥分类。LLM 仅在模式匹配命中时调用且结果缓存，控制开销。

def _bmh_search(data: bytes, pattern: bytes, start: int = 0) -> int:
    _dl = len(data)
    _pl = len(pattern)
    if _pl == 0 or _dl < _pl:
        return -1
    _skip = {}
    for _i in range(_pl - 1):
        _skip[pattern[_i]] = _pl - 1 - _i
    _pos = start
    while _pos <= _dl - _pl:
        _j = _pl - 1
        while _j >= 0 and data[_pos + _j] == pattern[_j]:
            _j -= 1
        if _j < 0:
            return _pos
        _bc = data[_pos + _pl - 1]
        _pos += _skip.get(_bc, _pl)
    return -1


def _match_full_sbox(data: bytes, sbox: bytes, start: int) -> bool:
    _dl = len(data)
    if start + 256 > _dl:
        return False
    for _i in range(256):
        if data[start + _i] != sbox[_i]:
            return False
    return True

# ==== Format-Preserving Encryption (FPE) 检测 ====
# FPE 加密后密文与明文具有相同格式 (长度和字符集), 常用于:
#   - 令牌化 (tokenization): 信用卡号、社会保险号的格式保留
#   - 数据库列级加密: 不改变 schema 限制
#   - 合规性要求: PCI-DSS (支付卡行业数据安全标准) 推荐使用FPE保护PAN
#
# 覆盖标准: NIST SP 800-38G Rev.1 (2024), ANSI X9.124-4.
# 算法: FF1 (Feistel-based, 10 rounds), FF3-1 (修正版, 8 rounds).
# 2024年 NIST 修订了 SP 800-38G: FF3→FF3-1 修复了原始 FF3 的伪造攻击 (Durak-Vaudenay, CRYPTO 2017).
#
# 检测策略:
#   (1) FF1 参数指纹: radix ∈ [2, 2^16], min_len ≥ 2, max_len ≤ 2^32
#   (2) FF3-1 参数指纹: radix ∈ [2, 2^16], min_len ≥ 2, max_len ≤ 2^32
#       较小 tweak (7 bytes instead of 8) 和 8-round Feistel 结构
#   (3) 库字符串: libfpe (NIST ref), Botan::FPE, Crypto++ FPE, Voltage FPE (Micro Focus/HPE),
#       Prime Factors EncryptRIGHT, comforte SecurDPS, Thales CipherTrust
#   (4) FPE 特有的 AES 子密钥派生 (CBC-MAC 变体 + 整数除法和取模运算组合)
#
# 参考: Bellare-Rogaway-Spies (FFX mode, 2010), Dworkin (NIST SP 800-38G Rev.1, 2024),
#  Durak-Vaudenay (FF3 attack at CRYPTO 2017), Hoang-Miller-Trieu (FF3-1 fix, 2019).
# 2026-08-01: 新增 BPS (Brier-Peyrin-Stern, 2010) 格式保留模式检测,

# ---- ASN.1 DER 基础解析 ----
def _read_tag(data: bytes, offset: int) -> Tuple[int, int, int, int]:
    """返回 (tag, length, value_offset, next_offset)"""
    _tag = data[offset]
    _len = data[offset + 1]
    if _len < 0x80:
        return _tag, _len, offset + 2, offset + 2 + _len

    _len_bytes = _len & 0x7F
    _val_len = 0
    for _i in range(_len_bytes):
        _val_len = (_val_len << 8) | data[offset + 2 + _i]
    _vo = offset + 2 + _len_bytes
    return _tag, _val_len, _vo, _vo + _val_len

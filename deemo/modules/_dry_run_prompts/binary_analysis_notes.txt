"""Path diversity tracking for anti-explosion in symbolic execution.

Path explosion is constrained by selecting maximally dissimilar paths.
This module computes pairwise similarity across structural, semantic,
constraint, and coverage feature dimensions, clusters paths by a
similarity threshold, and selects representatives from each cluster
to maximize exploration diversity.

增强 — LSH (Locality-Sensitive Hashing) 加速相似度搜索：
使用随机超平面投影将路径特征向量映射到汉明空间，
近似 KNN 查询时间复杂度从 O(n²·d) 降至 O(k·d·log n)。
SimHash 指纹用于快速去重：两路径 SimHash 不同 → 必定不相似，
避免昂贵的精确相似度计算。

增强 — WEIGHTED_SAMPLE 策略：
按簇大小的反比抽样 —— 小路簇的代表被选中的概率更高，
防止少数大簇垄断探索预算。

增强 — 近似最近邻索引 (ANN via Random Projection Forest)：
构建 ann_forest —— 多棵随机投影树的森林，每棵树在随机超平面上
递归分割特征空间。构建 O(n·log n)，查询 O(log n)，替代原始的
O(n²) pairwise 比较。

增强 — 多样性预算管理 (DiversityBudget)：
将总路径预算按 cluster_quota = max_paths / num_clusters 均分。

## 当前模块描述
输出模块：报告生成、web API、证据链报告。将分析结论汇总为结构化报告与证据链。

## 设计的深度创新点: 事件溯源可审计证据链报告 (EventSourcedEvidence)

### 创新动机与理论依据
现有证据链报告为静态快照，无法追溯推导过程。借鉴 ESAA-Security的事件溯源架构：将每次分析动作（输入、中间结论、来源引用）记录为事件序列，报告生成时按事件回放重建证据链；借鉴 DEER 的报告结构基准评估报告的信息完整性；引入逻辑一致性检查避免结论跳步。差异点：现有报告只含结论，新增方案记录推导事件并支持回放审计。

### 支撑论文
  [1] ESAA-Security: An Event-Sourced, Verifiable Architecture for Agent-Assisted Security Audits of AI-Generated Code — arXiv:2603.06365 (2026).
  [2] DEER: A Benchmark for Evaluating Deep Research Agents on Expert Report Generation — arXiv:2512.17776 (2025).
  [3] ReportLogic: Evaluating Logical Quality in Deep Research Reports — arXiv:2602.18446 (2026).

"""
证据链驱动的自适应报告引擎 — RAVEN + Veritas 启发。

理论依据:
  RAVEN (arXiv:2604.17948): 4-agent RAG 框架 → Project Zero RCA 模板。
  Veritas (arXiv:2605.15097): 证据驱动三段式验证 → 90% 召回, 零误报。

模块位置: output/evidence_chain_report.py
"""

import json, hashlib
from dataclasses import dataclass, field
from enum import Enum
from typing import Any, Dict, List, Optional
import logging
_log = logging.getLogger(__name__)


class ReportAudience(Enum):
    EXECUTIVE = "executive"
    TECHNICAL = "technical"
    COMPLIANCE = "compliance"


@dataclass
class EvidenceNode:
    """证据链节点 — 追溯每个发现的来源。"""
    finding_id: str
    source_module: str           # ai_ml | crypto | vuln | analysis | ...
    evidence_type: str           # static | dynamic | llm | fuzz | symbex
    confidence: float
    intermediate_results: Dict = field(default_factory=dict)
    children: List["EvidenceNode"] = field(default_factory=list)


@dataclass
class ReportSection:
    """报告章节 — 自适应格式。"""
    title: str
    content: str
    severity: str = "INFO"
    evidence_chain: Optional[EvidenceNode] = None
    collapsible: bool = True


class EvidenceChainReporter:
    """
    证据链追踪报告生成器 — RAVEN 启发。

    核心功能:
      1. 每个发现自动关联证据链 (哪个模块产生、哪些中间结果支撑)
      2. 根据受众自适应格式 (高管摘要/技术深度/合规审计)
      3. RAG 增强的 AI 摘要生成
    """

    def __init__(self, api_key: str = ""):
        self._api_key = api_key
        self._evidence_registry: Dict[str, EvidenceNode] = {}

    def register_evidence(self, finding_id: str, node: EvidenceNode):
        self._evidence_registry[finding_id] = node

    def generate_report(
        self, findings: List[Dict], audience: ReportAudience = ReportAudience.TECHNICAL
    ) -> str:
        """生成自适应格式报告。"""
        sections = []
        for f in findings:
            fid = f.get("id", hashlib.md5(str(f).encode()).hexdigest()[:8])
            evidence = self._evidence_registry.get(fid)
            chain_text = self._format_evidence_chain(evidence) if evidence else ""

            if audience == ReportAudience.EXECUTIVE:
                sections.append(self._exec_section(f, chain_text))
            elif audience == ReportAudience.COMPLIANCE:
                sections.append(self._compliance_section(f, chain_text))
            else:
                sections.append(self._technical_section(f, chain_text))

        return "\n\n".join(sections)

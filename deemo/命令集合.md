# 命令集合

本文档用于集中记录 `binmind` 的常用命令。

## 安装与帮助

```bash
# 安装系统依赖、Python 依赖，并注册 binmind 命令
chmod +x install.sh binmind
./install.sh --system

# 安装到当前用户目录
./install.sh --user

# 只注册命令，不安装依赖
./install.sh --system --no-deps

# 查看安装脚本帮助
./install.sh -help

# 查看 binmind 命令帮助
binmind -help
```

## AI 服务配置

AI 服务不通过环境变量配置。请直接编辑 `config.py` 中的 `Config` 类。

```python
# OpenAI
AI_PROVIDER = AI_PROVIDER_OPENAI
OPENAI_API_KEY = 'sk-xxxx'
OPENAI_MODEL = 'gpt-4'

# Azure OpenAI
AI_PROVIDER = AI_PROVIDER_AZURE
AZURE_API_KEY = 'xxx'
AZURE_ENDPOINT = 'https://xxx.openai.azure.com/'
AZURE_DEPLOYMENT = 'xxx'

# Ollama
AI_PROVIDER = AI_PROVIDER_OLLAMA
OLLAMA_HOST = 'http://localhost:11434'
OLLAMA_MODEL = 'llama2'

# 自定义 OpenAI 兼容 API
AI_PROVIDER = AI_PROVIDER_CUSTOM
CUSTOM_API_KEY = 'xxx'
CUSTOM_BASE_URL = 'https://api.example.com/v1'
CUSTOM_MODEL = 'your-model'
```

## 基础分析

```bash
# 分析一个二进制文件
binmind ./your_binary.elf

# 指定要分析的函数
binmind ./your_binary.elf -f main vuln win

# 禁用 AI，只使用启发式分析
binmind ./your_binary.elf --no-ai

# 跳过依赖检查
binmind ./your_binary.elf --skip-deps-check

# 指定输出目录
binmind ./your_binary.elf -o ./reports

# 指定报告格式
binmind ./your_binary.elf --format markdown
binmind ./your_binary.elf --format json
binmind ./your_binary.elf --format html
binmind ./your_binary.elf --format all
```

## 反编译与符号执行

```bash
# 自动选择反编译引擎
binmind ./your_binary.elf --decompiler auto

# 指定 radare2
binmind ./your_binary.elf --decompiler radare2

# 启用符号执行
binmind ./your_binary.elf --enable-symbolic-execution

# 启用静态污点分析
binmind ./your_binary.elf --static-taint

# 指定静态污点分析目标函数
binmind ./your_binary.elf --static-taint --taint-function main
```

## 崩溃数据分析

```bash
# 自动识别崩溃数据格式
binmind ./your_binary.elf --crash crash_data.json

# 指定崩溃数据格式
binmind ./your_binary.elf --crash crash_data.json --crash-format json
binmind ./your_binary.elf --crash crash.log --crash-format gdb
binmind ./your_binary.elf --crash asan.log --crash-format asan

# 在控制台打印崩溃分析摘要
binmind ./your_binary.elf --crash crash_data.json --print-report
```

## 利用脚本与沙箱

```bash
# 生成利用脚本，但不执行
binmind ./your_binary.elf --validate

# 允许实际执行利用脚本
binmind ./your_binary.elf --validate --exec

# 使用 Docker 沙箱执行
binmind ./your_binary.elf --validate --exec --sandbox docker

# 使用 Podman 沙箱执行
binmind ./your_binary.elf --validate --exec --sandbox podman

# 跳过 ROP gadget 分析
binmind ./your_binary.elf --no-rop

# 启用专家模式
binmind ./your_binary.elf --expert
```

## 并行与交互

```bash
# 启用交互式分析
binmind ./your_binary.elf --interactive

# 并行分析多个函数
binmind ./your_binary.elf --parallel --max-parallel 4
```

## Fuzzer 与 Ghidra

```bash
# 生成 libFuzzer harness
binmind ./your_binary.elf --fuzzer libfuzzer --fuzzer-harness ./harness.c

# 生成 AFL harness
binmind ./your_binary.elf --fuzzer afl --fuzzer-harness ./harness.c

# 导出符号执行产生的语料
binmind ./your_binary.elf --enable-symbolic-execution --export-corpus ./corpus

# 生成 Ghidra 标注脚本
binmind ./your_binary.elf --ghidra-script ./ghidra_annotations.py
```

## CVE 查询

```bash
# 按 CVE ID 查询
binmind --cve-query --cve-id CVE-2024-12345

# 按软件包名查询
binmind --cve-query --cve-package openssl

# 按二进制文件名查询
binmind --cve-query --cve-binary libc.so.6

# 指定数据源
binmind --cve-query --cve-package openssl --cve-source nvd

# 不使用缓存
binmind --cve-query --cve-package openssl --cve-no-cache

# 导出 CVE 查询结果
binmind --cve-query --cve-package openssl --cve-json ./reports/cve_openssl.json
```

## 健康检查与服务

```bash
# 运行健康检查
binmind --health
binmind --doctor

# 启动 Web API 服务
binmind --server

# 指定服务监听地址和端口
binmind --server --host 127.0.0.1 --port 9000

# 启用调试日志
binmind ./your_binary.elf --debug

# 指定日志级别
binmind ./your_binary.elf --log-level DEBUG
```

\begin{abstract}
We present \textsc{BinMind}, a multi-class binary vulnerability detection framework
operating on decompiled intermediate representations (IR) without requiring source
code, debug symbols, or dynamic execution. 

Our key contribution is a four-stage heap overflow false positive reduction pipeline
combining glibc alignment-aware boundary checking, realloc expansion tracking, struct
field pattern recognition, and free-reset detection. On a 10-scenario IR-level
benchmark (5 true overflows + 5 false positive patterns), the pipeline achieves
\textbf{100\% precision} (3/3 TP, 0/5 FP), eliminating all false positives that
naive allocation-to-write-site comparison would report. Baseline regex-based detection
achieves only 37.5\% precision on the same benchmark.

On 90 hand-crafted CVE-mirroring samples across six vulnerability types, BinMind
processes each function in under 1ms while maintaining 71.4\% overall detection
accuracy. We compare against Angr symbolic execution, QEMU user-mode tracing, and
Ghidra headless analysis, demonstrating competitive recall at orders-of-magnitude
lower analysis cost. BinMind requires no execution, no type recovery, and no
hardware-specific features---making it applicable to stripped COTS binaries across
x86-64 and ARM architectures.
\end{abstract}

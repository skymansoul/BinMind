## 所有命令行



### 基础分析

```bash
python main.py ./binary.elf                                          # 基本分析（默认 main/vuln 等函数）
python main.py ./binary.elf -f func1 func2                           # 指定分析函数
python main.py ./binary.elf --crash crash.json                       # 崩溃数据分析（自动识别格式）
python main.py ./binary.elf --crash crash.txt --crash-format gdb     # 崩溃数据分析（指定 GDB 格式）
python main.py ./binary.elf --print-report                           # 打印崩溃报告到控制台
python main.py ./binary.elf -o ./out --format html                   # 输出 HTML 报告到指定目录
python main.py ./binary.elf --format all                             # 生成所有格式报告
python main.py ./binary.elf --no-ai                                  # 仅用启发式分析，禁用 AI
python main.py ./binary.elf --decompiler radare2                     # 指定反编译引擎（radare2）
python main.py ./binary.elf --decompiler ghidra                      # 指定反编译引擎（Ghidra）
python main.py ./binary.elf --decompiler ida                         # 指定反编译引擎（IDA）
python main.py ./binary.elf --decompiler binaryninja                 # 指定反编译引擎（Binary Ninja）
python main.py ./binary.elf --decompiler hopper                      # 指定反编译引擎（Hopper）
python main.py ./binary.elf --expert                                 # 专家模式，AI 生成高级利用链
python main.py ./binary.elf --explain-pseudocode main                # AI 解释函数伪代码
```
